

## TagFlow Media — 实现计划

### 1. 数据层 (Dexie.js + IndexedDB)
- 安装 `dexie` 和 `react-dexie` hooks
- 创建数据库：`mediaItems` 表（id, filename, path, tags[], year, resolution, rating, addedAt）和 `tags` 表（id, name, category, color）
- 标签类别预设：年份(灰色)、类型(蓝色)、画质(绿色)、自定义(紫色)
- 文件名解析工具函数：从 `Inception.2010.2160p.mkv` 自动提取年份、分辨率生成初始标签

### 2. 布局与导航
- 深蓝色调主题（覆盖 CSS 变量）
- 左侧：智能标签栏（使用 Shadcn Sidebar），显示所有标签，按类别分组，支持多选交集过滤
- 顶部：搜索框（支持 `tag:科幻 rating>8` 语法）+ 视图切换（网格/紧凑列表）+ 导入按钮
- 主区域：媒体网格/列表

### 3. 主页面 — 媒体浏览
- 安装 `react-window` 实现虚拟滚动网格
- **网格模式**：海报卡片 + 文件名 + 彩色标签气泡
- **紧凑模式**：纯文字行 + 彩色标签气泡，无海报
- 批量选择：Ctrl/Shift 多选 + 框选，选中后底部浮动工具栏（添加/移除标签）
- 右键菜单：快速打标签、查看详情

### 4. 媒体详情弹窗
- 显示文件名、完整路径、所有标签、年份、分辨率、评分
- 编辑标签、评分
- "打开本地位置"按钮（显示提示：需配合本地脚本）

### 5. 标签管理面板（独立页面）
- 列表展示所有标签，显示关联媒体数量
- 重命名标签
- 合并标签（选两个标签合并为一个）
- 批量删除标签

### 6. 搜索引擎
- 解析简易语法：`tag:科幻 tag:4K rating>8 year:2020`
- 支持普通文本模糊搜索文件名
- 实时过滤，结合侧边栏标签选择

### 7. 数据导入
- "导入 JSON" 按钮，接受 JSON 文件上传
- 预期格式：`[{filename, path, tags?, year?, resolution?}]`
- 导入时自动执行文件名解析补全缺失字段
- 显示导入进度和结果统计

### 8. 页面路由
- `/` — 媒体浏览主页
- `/tags` — 标签管理面板
